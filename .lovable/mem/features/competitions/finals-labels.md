---
name: Competition finals labels and import duplicates
description: Spreadsheet finals labels must appear on competition fixtures; re-importing the same fixtures must be blocked
type: feature
---
Competition fixture imports must retain Finals, Semi Final, Grand Final and similar labels from the spreadsheet (Round column, or any other column such as Notes mentioning finals) and display them on fixture cards and as the section heading, including games with TBD teams and pitches.

Imports must not create duplicate fixtures: a row matching an existing game (same date/time and same teams, either order; TBD-vs-TBD also compares venue/pitch) or repeated in the same file is shown as "already imported" and skipped.
